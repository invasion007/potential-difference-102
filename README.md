# 10.2 电势差 · 可交互课件

高中物理（人教版必修第三册）10.2 节交互可视化课件。**单文件、零外链、断网可开。**

主线：**电场 → 试探电荷 → 做功 W = qU → 电势差 U_AB = W/q → 与 q 无关**。

## 在线访问

https://invasion007.github.io/potential-difference-102/

## 看点

- **φ 地形面**：面高就是电势 φ，拖动零电势面整面平移 —— φ 变、U 不变
- **黄色量规**：两根白柱之间的竖直尺寸线 = 电势差 U，本课主角量
- **金色 W 柱**：换试探电荷 q 时柱变号变高，黄色量规纹丝不动 —— 分清"电场的事"与"电荷的事"
- **第 19 步反证法**：拖动灰色斜面，θ≠0 就出现沿面分量 → 做功矛盾 → 推出等势面必须 ⟂ 电场

## 科学性

电势 φ(x) = E(x₀ − x) 与电势差 U_AB = φA − φB 由解析式给出，逐条断言锁住；
换 q 时地形面严格不动（断言误差为 0）。
